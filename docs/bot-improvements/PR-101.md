# Журнал изменений PR #101

## Проход 10 октября, 01:47 МСК — явный пересмотр опубликованной версии

Все проверенные CI #83/#84 и открытых #93–#100 успешны, конфликтов с текущим main нет. Исправлен недостаток объяснения: бот мог назвать новую карту без указания, что его прежний выбор был другим. В ответе по ряду, нескольким рядам и сводной версии теперь добавляется «Пересмотрел выбор: … → …», за которым идут обычные основания текущего выбора.

Прежний выбор извлекается только из собственных публичных сообщений этого обсуждения: последняя однозначно приложенная карта нужного ряда. Несколько карт одного ряда не трактуются как определённый выбор. При совпадении или отсутствии прежней карты пересмотр не объявляется. Это фиксация изменения и объяснение текущей версии, не утверждение о том, какая конкретная реплика вызвала изменение. При предельной длине текста остаётся существующее сокращение ответа.

Проверки: 38 тестов обсуждения и песочницы прошли, включая четыре новых случая — смена карты, неизменность, отсутствие прежней карты ряда, уже обновлённая версия. Регрессионный случай смены падал до исправления. Решения, веса, клиент и БД не менялись, развёртывания не было.
