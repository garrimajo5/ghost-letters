# План: редизайн стола (основная версия + «Досье»-сеанс)

_Начат 11.10.2026._ Прототипы: холст «Письма призрака — варианты редизайна стола» (артборды «Основная версия · вся партия» и «„Досье“ · сеанс · вся партия»). Правила UX — в проекте, `claude/REDESIGN_VARIANTS.md`.

## Принципы
- Каждый этап — отдельный PR в `main`, CI зелёный. Ничего не ломать: боты, песочница, рейтинг, картотека карт, «Что нового», экран стола, зрители, альбомная раскладка.
- Новый основной стол включён по умолчанию, но в настройках есть «Классический стол» — возврат к прежнему интерфейсу, если что-то пойдёт не так.
- «Досье» (`DOSSIER_DESIGN`) получает сеанс; основная сборка его не видит.
- Закрытая информация: верность рядов — только в итогах; голоса за Убийцу — после завершения голосования (сервер уже так отдаёт).
- Всё, что человек показывает на стол, уходит в чат в формате заметок `TableReasoning`, чтобы боты читали.
- Никаких видимых полос прокрутки; ленты листаются свайпом.
