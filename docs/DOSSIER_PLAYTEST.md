# Тестовый интерфейс «Досье»

Альтернативная рабочая веб-сборка использует те же API и правила игры.
Авторизация и партии общие с основным сайтом. Для проверки рекомендуется
создать отдельную нерейтинговую комнату с ботами.

Флаг `DOSSIER_DESIGN` выключен по умолчанию. Основная веб-сборка, Android
и iOS сохраняют привычный интерфейс. В тестовой сборке есть метка «ДОСЬЕ · ТЕСТ».

## Что проверять

- Выбор автора показывает его последнюю публичную версию; командные сообщения скрыты.
- В режиме «Сейчас говорят» новые реплики идут последовательно, связи появляются
  постепенно; доступны пауза и полный разговор. При большой пачке снимков показывается
  последняя реплика, без проигрывания всей истории.
- Связи подсвечиваются непосредственно на поле. Это мнение игрока, а не истина.
- Текст появляется по буквам, как в visual novel. Пауза сохраняет место;
  нажатие на текст или «Показать сразу» раскрывает реплику целиком.
  При упоминании позиции карты появляется аватар автора с отметкой снизу:
  галочка — поддержка, крестик — исключение, лупа — только проверка.
  Структурированные ссылки без явного названия в тексте показываются отдельными
  последовательными пояснениями с миниатюрой карты, без выдумывания аргументов.
- Подсказки Призрака всех раундов раскрываются в нижней сворачиваемой панели.
- «Моя версия» открывает существующий редактор с источниками карт и голосовым пояснением.
- Рука сворачивается вне отправки письма. Голосование, Призрак, ночной выбор,
  командный разговор, награды, реванш и просмотр зрителем используют существующие действия.

Это первая игровая реализация макета: домашний экран и лобби пока прежние,
новые тексты для ботов не генерируются — показываются настоящие сообщения сервера.

## Сборка

Из `client/`:

```sh
flutter pub get
flutter analyze
flutter test
flutter test --dart-define=DOSSIER_DESIGN=true test/dossier_test.dart
flutter build web --release --base-href=/download/dossier/ --dart-define=DOSSIER_DESIGN=true --dart-define=APP_VERSION=0.1.3-dossier --pwa-strategy=none
```

Содержимое `client/build/web` размещается **только** в отдельной директории
`/opt/ghost-letters/www/download/dossier/`. Существующий обработчик Caddy
`/download*` обслуживает её без смены конфигурации или перезапуска API.
Основная папка `www/web` и файлы APK не меняются. Для обновления нужно сначала
распаковать сборку в соседнюю временную папку и заменить только `dossier`.
Для отката достаточно вернуть предыдущую папку тестовой сборки.

Отдельный путь сохраняется при обычном деплое сайта. Маршрутизация Flutter
использует URL-фрагмент `#/game/...`, поэтому обновление страницы работает
с существующим статическим обработчиком. Сервис-воркер отключён для тестовой сборки.
