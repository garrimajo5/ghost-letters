# Журнал ходов ботов

Из корня репозитория соберите инструмент и запустите одну партию с номером расклада.

```sh
dotnet build server/tools/BotTrace
dotnet run --no-build --project server/tools/BotTrace -- 1000 > trace.json
```

После номера можно указать сценарий `full-game`, `clear-hints` или `witness-reveal`. Один номер, сценарий, каталог карт и версия игры воспроизводят одну последовательность решений. В веб-клиенте те же прогоны доступны администратору в меню «Песочница ботов» → «Быстрый журнал ходов». Сервер использует активный каталог со своими правками, локальный запуск читает каталог из репозитория.

В JSON поле `actions` содержит ходы по порядку. У каждого хода есть раунд, автор, команда с выбранными картами или голосом и новые реплики с пометками. Словари `players`, `roles` и `cardNames` расшифровывают идентификаторы. Поле и истина доступны для проверки версии. Код завершения 0 означает, что партия дошла до результата.
