# Трейлер «Письма призрака»

Готовые версии: `out/ghost-letters-trailer-16x9.mp4` и `out/ghost-letters-trailer-9x16.mp4`. Обновлённый монтаж: 98,494 с по музыке (98,500 с по видеокадрам), 29 сцен, 30 fps. Вертикальная версия перекомпонована: заголовки разбиты на строки, пара экранов располагается по высоте. Сводки кадров: `out/contact_sheet.jpg` и `out/contact_sheet_9x16.jpg`.

По запросу владельца переход около 32-й секунды дополнен ночной паузой. Музыка плавно затихает с 29,768 до 33,440 с; на 31,625 с появляется «ГОРОД ЗАСЫПАЕТ», а с 33,440 до 37,154 с Убийца последовательно выбирает четыре карты в настоящем интерфейсе игры. На 37,154 с музыка резко возвращается вместе со сменой сцены. Вставлены два такта (3,714 с), поэтому последующие кадры, титры и музыкальные акценты сдвинуты на ту же величину. Требования брифа о неизменной музыке и длительности 94,78 с заменены этой редакторской правкой; прочие проверки сохранены.

Короткий фрагмент перехода для просмотра: `out/night-transition-preview.mp4` (28–41 с полной версии).

## Пересборка одной командой

Требуется Python 3.10+ и зависимости из `requirements.txt`:

```sh
python -m pip install -r trailer/requirements.txt
python trailer/build.py --all
```

Одна ориентация: `python trailer/build.py --format 16x9` или `--format 9x16`. FFmpeg берётся из imageio-ffmpeg; можно задать путь переменной `FFMPEG`. Рендер работает локально, без сетевых сервисов. Рабочие кадры и временное видео пишутся в игнорируемую `.work/`.

Все монтажные решения редактируются в `scenes.json`: 29 интервалов, смены по долям внутри сцен (`steps`), титры и их интервалы, пути к иллюстрациям/записям, шрифты, финальный призыв и затемнение. Параметры ночной паузы — в `music_edit`: место вставки, начало затухания, длина паузы и 8 мс для устранения щелчка при резком входе. Времена взяты из `music/markers.json`, а не округлённой таблицы; сетка после вставки пересчитывается и сохраняется в `out/timeline_markers.json`. Начало ролика 0 — исключение к сетке: первая доля трека начинается на 0,056 с. Завершение плавного затемнения — не склейка.

Название игры задаётся массивом `logo`, призыв — последним элементом `titles`. Для нескольких строк используется массив `lines`, отдельный перенос для вертикального экрана — `vertical`. Заголовки остаются в безопасной зоне 5%; при необходимости размер автоматически уменьшается. Два альбомных скриншота приближены через `asset_crops`, без изменения пропорций или перерисовки интерфейса.

Музыка берётся из `music/trailer_music_1m35.mp3`. `music_edit.py` применяет плавное затухание по половине косинусной кривой, добавляет два такта тишины и возвращает следующий фрагмент в исходном темпе. Промежуточный звук сохраняется без потерь в `.work/`, затем кодируется в AAC 192 kbps при сборке видео. Исходный файл музыки и `music/markers.json` сохранены без изменений. Оба формата используют один и тот же отредактированный звук. Чтобы собрать первоначальную музыкальную версию, необходимо удалить `music_edit` и вернуть исходные тайминги сцен.

## Повторная съёмка экранов

Съёмка использует **способ B из раздела 5**: настоящие production-виджеты Flutter и ассеты клиента, с постановочными данными вместо сервера. Это позволяет повторить редкие роли, ночные подсказки, голосование и финал без случайной раздачи. Это не запись живого сетевого матча и не нарисованный макет интерфейса.

Из корня репозитория:

```sh
cd client
flutter pub get
flutter test ../trailer/capture/capture_test.dart
cd ..
python trailer/build.py --all
```

Фотограф расположен только в `trailer/capture/` и не попадает в обычный `flutter test` клиента. Загружаются Oswald, GolosText и MaterialIcons. Перед снимками прогреваются изображения. Портрет: 412×915 logical px, DPR 3 (PNG 1236×2745). Альбом: 1366×1024, DPR 2 (PNG 2732×2048). Только шесть указанных в брифе имён ботов; реальные аккаунты и адрес сервера не используются.

`captures/C1.png` — `C18.png` соответствуют списку брифа. Дополнительно сохранены `C2-lobby.png` (лобби перед выбором бота) и `C9-radio.png` (экран с рацией перед открытием чата).

Для C4/C6/C8/C11/C12 фотограф сохраняет 4-секундные последовательности, 12 fps: выбор истинных карт Убийцей, выбор и отправка письма, приход подсказки, приближение поля, выбор и приём голоса. `build.py` собирает их в `captures/C*-motion.mp4`; эти готовые записи включены в PR. Они воспроизводятся в исходном темпе. Промежуточные PNG последовательностей игнорируются Git. Нечётная высота телефона при кодировании дополняется одной строкой, а не растягивается. В ночной вставке C4 кадрируется до заголовка ночи и поля: видны все четыре выбираемые карты.

Кадр города `assets/city-night.png` создан встроенным imagegen для этой вставки; окончательный промпт сохранён в `assets/city-night-prompt.txt`. Это атмосферная иллюстрация, а выбор карт снят с production-виджетов. В вертикальной версии центр композиции сохраняет особняк и улицу. Во время сцены изображение плавно темнеет.

## Проверка

Установите ffprobe из своей сборки FFmpeg и добавьте его в PATH либо укажите `FFPROBE`. Сборки Windows доступны у [Gyan](https://www.gyan.dev/ffmpeg/builds/). Затем:

```sh
python trailer/verify.py
```

Проверка печатает «сцена → время → ближайшая доля → расхождение» для всех основных и внутренних склеек. Для смены сцен используется ближайший кадр, для смены карты внутри такта — первый кадр не раньше доли; ошибка не превышает 1/30 с. Проверяются ffprobe-параметры, полное декодирование, размер ≤40 МБ, длительность из конфига с допуском одного кадра, faststart, −14±0,5 LUFS и чёрный хвост. Отдельно измеряется уровень звука перед затуханием, в его конце, внутри паузы и после возврата музыки в готовых MP4. Из середины каждой сцены извлекается кадр; оригиналы лежат в `out/frames-*`, сводки — в `out/contact_sheet*.jpg`. Результаты: `out/validation.json`.

В нескольких случаях титр меняется посередине сцены, поэтому кадр contact sheet может попадать в его короткое появление. В ролике длительность каждого титра не меньше 1,8 с. Вопрос «КТО УБИЙЦА?» начинается на долю раньше чёрного кадра и продолжается через следующий монтажный стык: так он остаётся читаемым дольше 1,5 с.

## Источники и изменения

Бриф, музыкальный монтаж и reference sheets взяты из `origin/trailer/brief` (f39f094), поскольку при начале работы в main каталога trailer не было. Рабочая ветка создана от main e26dd05. Все изменения PR ограничены `trailer/`; код приложения и сервера не меняется.

Иллюстрации и шрифты берутся из существующих ассетов репозитория. Музыка — предоставленный владельцем трек Suno из брифа; новая лицензия на неё не назначается. Отдельные иллюстрации не увеличиваются более чем в 1,6 раза (включая плавное приближение). Небольшие исходники используются как карточки, чтобы не растягивать 360 px на весь Full HD кадр. Скриншоты сняты с высоким DPR; пропорции сохраняются.
